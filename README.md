# عناد الروقي · Enad Alrougi

Personal site: **https://ide21.github.io**

Bilingual (Arabic / English), light and dark mode, designed in FigCraft.

## Editing

- All text (both languages), projects, experience and links: `public/content.js`
- Layout and components: `src/app.jsx`
- Colours and the scroll effect: `src/input.css`

Every push to `main` builds and publishes the site automatically (GitHub Actions → GitHub Pages).

## Run locally

```bash
npm install
npm run dev
```
